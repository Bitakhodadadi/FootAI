# ⚽ FootAI | دستیار هوشمند فوتبال

**سازنده:** آرتین قره‌داغی  
**مدرس:** بیتا خدادادی

بازیکن آمار یک مسابقه را وارد می‌کند و FootAI این‌ها را نشان می‌دهد:

- **گزارش پایه** که همان لحظه در مرورگر حساب می‌شود (بدون نیاز به اینترنت یا کلید): دقت پاس، دقت شوت، امتیاز از ۱۰، نقاط قوت، موارد نیازمند تمرین و نقشه جای‌گیری روی زمین.
- **تحلیل هوش مصنوعی** با DeepSeek: خلاصه عملکرد، برنامه تمرینی هفته و پیشنهاد جای‌گیری مخصوص پست بازیکن.

> ⚠️ این پروژه آموزشی است و جای نظر مربی را نمی‌گیرد.

## انتشار روی GitHub Pages

1. در GitHub یک repository جدید و **Public** بسازید (مثلاً `FootAI`).
2. روی **Add file → Upload files** بزنید و **همه فایل‌های داخل زیپ** را بکشید داخل صفحه. فایل `index.html` باید در صفحه اصلی repository باشد، نه داخل یک پوشه دیگر. بعد روی **Commit changes** بزنید.
3. به **Settings → Pages** بروید.
4. در **Build and deployment → Source** گزینه **Deploy from a branch** را انتخاب کنید.
5. Branch را روی `main` و پوشه را روی `/ (root)` بگذارید و **Save** را بزنید.
6. یکی دو دقیقه صبر کنید تا آدرس سایت بالای همان صفحه ظاهر شود:
   `https://USERNAME.github.io/FootAI/`

## وارد کردن کلید API

1. سایت را باز کنید. کادر **🔑 اتصال به هوش مصنوعی** بالای صفحه است.
2. سرویس را انتخاب کنید:
   - **Metis (DeepSeek)**: کلید را از پنل [metisai.ir](https://metisai.ir) بگیرید.
   - **DeepSeek (سایت رسمی)**: کلید را از [platform.deepseek.com](https://platform.deepseek.com) بگیرید.
3. کلید را بچسبانید و **ذخیره و اتصال** را بزنید.

کلید فقط در `localStorage` مرورگر همان دستگاه ذخیره می‌شود و **هرگز وارد GitHub نمی‌شود**. روی هر دستگاه یا مرورگر جدید باید یک بار دوباره وارد شود. برای پاک کردن کلید، روی «تغییر کلید» بزنید.

اگر نام مدل در پنل شما فرق دارد، آن را در **تنظیمات پیشرفته** بنویسید (پیش‌فرض Metis: `deepseek-v4-flash` و پیش‌فرض DeepSeek: `deepseek-chat`).

> ⚠️ هیچ‌وقت کلید را داخل `script.js` ننویسید؛ چون repository عمومی است و هر کسی می‌تواند آن را ببیند و اعتبارتان را خرج کند.

## منطق برنامه (از پایتون تا سایت)

| برنامه پایتون | نسخه سایت |
|---|---|
| `input()` برای گرفتن اطلاعات | فرم با دکمه‌های + و −، انتخاب پست و بررسی خطا |
| `total_passes = correct + wrong` | همان، به‌علاوه نمایش زنده دقت پاس |
| `if accuracy >= 80` | چند سطح: عالی (۸۵٪ به بالا)، خوب (۷۵٪ به بالا)، متوسط (۶۰٪ به بالا)، ضعیف |
| `if shots >= 3` | همان، به‌علاوه دقت شوت (شوت در چارچوب ÷ کل شوت‌ها) |
| `if lost_balls >= 5` | به ازای هر ۹۰ دقیقه حساب می‌شود تا برای بازیکن تعویضی هم منصفانه باشد |
| `if position == ...` | ۵ پست با پیشنهاد جای‌گیری و نقشه زمین |
| — | امتیاز ۰ تا ۱۰ بر اساس پاس، گل، پاس گل، توپ‌گیری و مهار |
| — | تحلیل و برنامه تمرینی با هوش مصنوعی DeepSeek |

## مشکلات رایج

| مشکل | راه‌حل |
|---|---|
| سایت خطای 404 می‌دهد | `index.html` باید در ریشه repository باشد و Pages روی `main` و `/ (root)` تنظیم شده باشد. چند دقیقه صبر کنید. |
| «کلید API معتبر نیست» | کلید را دوباره و بدون فاصله وارد کنید و مطمئن شوید سرویس درست را انتخاب کرده‌اید. |
| «اعتبار حسابت تمام شده» | اعتبار حساب را در پنل سرویس بررسی کنید. |
| «اتصال به سرویس هوش مصنوعی برقرار نشد» | اینترنت را بررسی کنید. اگر وصل است، ممکن است آن سرویس اجازه درخواست مستقیم از مرورگر را ندهد (CORS)؛ سرویس دیگر را امتحان کنید. |
| «نام مدل پیدا نشد» | نام مدل را از پنل سرویس بردارید و در «تنظیمات پیشرفته» بنویسید. |
| تغییرات دیده نمی‌شود | صفحه را با Ctrl+F5 تازه کنید. |

## امنیت

- کلید فقط در مرورگر کاربر ذخیره می‌شود.
- پاسخ هوش مصنوعی و نام بازیکن با `textContent` نمایش داده می‌شوند، پس هیچ کدی از آن‌ها اجرا نمی‌شود.
- اگر کلیدی اشتباهی جایی منتشر شد، فوراً آن را در پنل سرویس باطل کنید و کلید جدید بسازید.
